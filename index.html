Featured project

A healthcare data platform, built as one system.

A simulated enterprise workflow connecting clinical, operational, and financial data through ingestion, warehouse modeling, machine learning, BI, and pipeline observability. Every phase feeds the next.

Working title · Clinical Intelligence Platform

Messy events in.
Trusted decisions out.

The platform will generate synthetic clinical, patient-flow, and financial records with realistic data problems; transform them into tested analytical models; and present care outcomes, operational performance, financial measures, and pipeline health. All project data is synthetic and excludes patient information and proprietary employer data.

Synthetic data only
Phase 01

Cloud data engineering

Python generator for clinical events, patient flow, and revenue-cycle records; Terraform, GCP, BigQuery, dbt, and automated quality checks.

Phase 02

Data science & ML

Leakage-aware readmission and length-of-stay demonstrations, resource-use context, persisted predictions, and model monitoring.

Phase 03

BI & observability

Power BI views for clinical outcomes, patient flow, financial performance, revenue-cycle measures, data freshness, and pipeline/model health.

Phase 04

Architecture & case study

System diagrams, design trade-offs, cost choices, limitations and reproducible technical documentation.

Engineering principles

Built to show judgment, not just code.

With AI now able to generate code in seconds, I designed this project to showcase the judgment that makes code useful in healthcare: sound architecture, trustworthy data and models, reliable operations, and clear communication of trade-offs.

01 / REALISTIC DATA

Make messiness explicit

Handle missing timestamps, nulls, duplicate events, late arrivals, and out-of-order records with documented rules and tests.

02 / TRUSTWORTHY MODELS

Protect validity

Use time-aware evaluation, prevent target leakage, track model versions, and explain why synthetic-model results are not clinical evidence.

03 / OPERABLE ANALYTICS

Measure the pipeline too

Show freshness, volume, quality failures, and model signals alongside business measures so reliability is part of the product.
